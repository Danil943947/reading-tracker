# Individual developer and workflow

**Owners:** One authorized student owns `lib/core/`, `lib/features/catalogue/`,
`lib/features/collection/`, `lib/features/auth/`, `lib/features/profile/`, `test/`, docs and releases.

**Workflow:** feature branches and meaningful commits. Use pull requests for review when
possible; do not invent a peer reviewer. Ask instructor to confirm solo exceptions to R1–R3.

**Contributions:** Generated from the actual repository using `git shortlog -sn` before defence.
No invented commits or contributors.

**Decisions:** See `docs/decisions.md`.

**Backend plan:** Public Open Library API (`openlibrary.org`); CRUD host to be selected and
recorded here in week 2. Fake mode has no HTTP backend.
